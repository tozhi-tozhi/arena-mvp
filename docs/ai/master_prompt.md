## 3. Architecture Philosophy

Phase 1: Single-player playable          [DONE]
   v
Phase 2: Content + progression           [2A DONE]
   v
Phase 3: The World (Area-based)          [3A–3E ✅ · 3F 🟡 เหลือมินิแมป + seamless zoom]
   v
Phase 3G: Polish (แสง สี เสียง ภาพ)      [P1 เสียง ✅ · P2 แฟลช ✅ · P3 แสงเงา ⏳ งานถัดไป · P4 ภาพจริง ⏳]
   v
Phase 4: Base เดินเล่นได้จริง             [⏳ เลื่อนไปหลัง Polish]
   v
Phase 5: Local co-op / Online            [OPTIONAL, NOT IN SCOPE]

กฎหลัก:

- อย่าออกแบบ Multiplayer จนทำให้ Single-player ซับซ้อน
- แยกความรับผิดชอบของ Scene, Entity, System, Data, UI ให้ชัดเจน
- **ตัวเลขปรับสมดุลต้องอยู่ในไฟล์ Data ไม่กระจายใน Scene** (มีหนี้ค้าง — ดูหัวข้อ 11)
- ใช้ระบบที่มีอยู่ซ้ำก่อนสร้างระบบใหม่
- ตัวเลขสมดุลของอัปเกรด/ดาว → `Upgrades.ts` ที่เดียว ทั้ง UI และเกมต่อสู้อ่านจากฟังก์ชันเดียวกัน
- **เพิ่มบอสใหม่ → แก้ 3 ไฟล์เท่านั้น:** `bosses.ts` (ชื่อ), `createBoss.ts` (Registry), `BossLoader.ts` (Asset) — `WorldScene.ts` และ `AreaBosses.ts` ห้ามแตะ
- **เพิ่มมอนสเตอร์เดินสุ่มชนิดใหม่ → ใช้ `CombatTarget` เดิม** ห้ามแก้ `PlayerActor.ts` (พิสูจน์แล้วกับตัวแทะกระดาษ)
- ห้ามทำ Backtracking / Chunk Streaming — แอเรียเก่าทิ้งได้ มีประตูวาปกลับฐาน
- **ของที่สร้างทุกเฟรมต้องแคช**: `CombatTarget` สร้างครั้งเดียวตอน spawn ห้ามสร้างใน `getTargets()` (บทเรียนบั๊ก multi-hit)
- ทุก Entity ต้องมี `destroy()` ที่ไม่ดรอปของ ไม่เรียก `onDeath` — ใช้ตอนล้างแอเรีย
- **ของตกพื้นทุกชิ้นต้องระบุ `source` ตอนสร้าง `DroppedItem`** (`'ground' | 'minion' | 'boss' | 'seal' | 'other'`) — ถ้าไม่ระบุจะได้ `'other'` ซึ่งไม่นับเควสเก็บของ
- **เสียงใหม่ทุกตัวเพิ่มใน `src/systems/sfx.ts` ที่เดียว** ห้ามสร้าง `AudioContext` เองที่อื่น · ระดับเสียงปรับที่ค่าคงที่บนสุดของไฟล์
- **กฎ Phaser 4 เรื่องสี/แฟลช (บังคับ):** ดูหัวข้อ 4.10

### 4.2 Boss Design Rules

- บอสทุกตัวต้องมีเอกลักษณ์ ห้ามแค่เพิ่ม HP/Damage
- Telegraph ต้องบอกพื้นที่/ทิศทางอันตราย
- ช่วง Rage ต้องเปลี่ยนรูปแบบการเล่น
- ระยะ/ขอบเขตทั้งหมดอิง `physics.world.bounds` ของแอเรียปัจจุบัน (แก้แล้วใน MayaBoss)
- บอสเกิดในสภาพ `setSleeping(true)` — ตื่นเมื่อผู้เล่นเข้าใกล้ `DETECT_RADIUS = 500` **ทีละตัว**
- ตัวที่ยังหลับ: ผู้เล่นตีไม่ได้ ครกจิ๋วไม่ยิงใส่ ไม่ปลุกตัวข้างเคียง
- เลือดบอสใน The World = เลือดฐาน × `hpMult` ของเขต (ห้องฝึกไม่คูณ) — `def` ถูก clone ใน `BossBase` แล้ว จึงไม่รั่วข้ามฉาก
- ดาเมจขาออกคูณที่ `bossHooks.onHitTarget` จุดเดียว ผ่าน `scaleBossDamage()` (`Math.round`, ขั้นต่ำ 1)
- ไฟไหม้คูณที่ `bossHooks.onBurn` ด้วย `burnMult` ของเขต

บอสที่มีอยู่:
- **ภัสมะ (Phasama)** — ตัวนิ่มลาวา: ไล่, พ่นไฟกรวยหมุน, พุ่งชน, คลั่งหมุนลูกข่าง มีมึนให้ตีกลับ (เลือดฐาน 80)
- **มายา (Maya)** — กระต่ายฝันร้าย: กระโดดโจมตี, กรงสามเหลี่ยม, หายตัวตุ้ม, แยกร่างปลอม เงาผิดทิศ (เลือดฐาน 70)

กฎร่างปลอมของมายา:
- เหมือนจริงทุกประการ ไม่กระพริบ ไม่ติดสี
- เบาะแสเดียว: **เงาทอดผิดทิศ** (แสงเกมจากซ้ายบน → ตัวจริงเงาขวาล่าง)
- ตีโดนได้ → แตกเป็นเศษกระดาษ + "ร่างปลอม!" + วางสามเหลี่ยมเล็กที่เท้าผู้เล่น (เลือดบอสไม่ลด)
- จำนวนร่าง: 2 ตัว (คลั่ง 3 ตัว)

### 4.3 Character Design Rules

- Sprite หันขวาเสมอ → โค้ด FlipX
- ระยะ/ขอบเขตทั้งหมดเทียบกับ `physics.world.bounds` ไม่ใช่ `WORLD_WIDTH/HEIGHT` หรือ `GAME_WIDTH/HEIGHT`
- การเล็งใช้ `cam.getWorldPoint()` (มี fallback สูตรซูม) — ห้ามกลับไปใช้ `pointer + scrollX` ตรง ๆ

| Character | Playstyle | Normal | Charged | Skill | Passive | HP |
|---|---|---|---|---|---|---|
| อัคนี | ประชิด/ฟันกวาด | ฟันสั้น | ฟัน+พุ่งดาบ | ฟันใหญ่ + อมตะ + ฟื้นเลือด | โดนตีจริงได้โล่ 1 ฮิต | 6 |
| ลูมิ | ระยะไกล/ยิง | กระสุนระเบิด | กระสุนพัด | แดช | ตีติด 8 ครั้งรีเซ็ตแดช | 4 |

ประตูสาธารณะของ PlayerActor ที่ฉากเรียกได้: `get hp()`, `heal(n)`, `takeDamage()`, `applyBurn()`, `setVictory()`, `endEncounter()`, `hitStop()`

### 4.4 มอนสเตอร์เดินสุ่ม + จุดฟื้นเลือด (Session 3 — ยืนยันผลแล้วใน Session 4)

**ตัวแทะกระดาษ (Minion)** — ทำให้แมพมีชีวิต ไม่ใช่แค่ของวางพื้น
- เป็น "สีสรรและความเสี่ยงเล็ก" **ไม่ใช่กำแพงความยาก** — ตัวเบา เดินหนีทันเสมอ
- ตื่นเสมอ (ไม่ใช้ระบบ sleep แบบบอส) แต่ไล่เมื่อเข้าใกล้ 260 เท่านั้น
- วงจร: เดินสุ่มรอบบ้าน → ไล่ → ง้าง (วงเตือน 430ms) → พุ่ง → นิ่งเปิดให้ตี → เลิกไล่กลับบ้านเมื่อผู้เล่นห่าง 720
- ตายคายของ 1 ชิ้นเสมอ (เรทตามเขต) → เป็นแหล่งความโลภ/ทรัพยากร **แต่ไม่นับเป็นความคืบหน้าเควสเก็บของ** (เปลี่ยนใน Session 4)
- **เลือดคงที่ 3 ทุกเขต ไม่คูณตามความลึก** (ตั้งใจ — บอสเป็นตัวแบกเส้นความยาก)
- ไม่นับเป็นเงื่อนไขปลดประตู

**เสาฟื้นเลือด (HealShrine)** — จุดพักที่มีราคา
- สุ่ม 0–2 จุดต่อแมพ (บางแมพไม่มี = ต้องบริหารเลือด)
- กด E แล้วยืนฟื้น **ทีละ 1 หน่วยทุก 600ms** ไม่ใช่ปุ่มฟรี
- หยุดฟื้นเมื่อ: เดินออกนอก 95px · **เลือดลดจากภายนอก (โดนตี)** · เลือดเต็ม · จบทริป
- มีตัวแทะเฝ้า 1 ตัวต่อจุดโดยตั้งใจ — การพักมีความเสี่ยงของตัวเอง

### 4.5 Rarity & Progression

Rarity 4 ระดับ: common (เทา) / rare (ฟ้า) / epic (ม่วง) / legendary (ทอง) — `src/data/rarity.ts`

ไอเทม 4 ตัว:

| Item | ใช้กับ |
|---|---|
| Ore (แร่) | Charm Lv.1–10 + ช่องถุง |
| Wood (ไม้) | Pet Lv.1–10 |
| Bone (กระดูก) | ดาวตัวละคร ★0–3 |
| Essence (ธาตุ) | ฟักไข่ (อนาคต) |

ดรอป: ภัสมะ → Ore + Essence · มายา → Wood + Bone

**เรทของดี (`rareBonus` ใช้งานจริง):**
- น้ำหนักฐาน: common 55 / rare 30 / epic 12 / legendary 3
- คูณ `rareBonus` **เฉพาะ rare/epic/legendary** — common คงเดิม สัดส่วนของดีจึงโตตามเขต
- ทุกทางได้ของใช้เรทเดียวกัน: ของตกพื้น · ดรอปบอส · ดรอปตัวแทะ · ของปลอบใจจากผนึกพัง
- จำนวนชิ้นที่บอสดรอป = `dropCount` ของเขต (4 → 5 → 6 → สูงสุด 8)

**วาล์วเศรษฐกิจตำนาน:** กล่องผนึกสำเร็จการันตี epic ขึ้นไป 2 ชิ้น และมีโอกาส legendary = `0.12 × rareBonus` (เขตตื้น 12% · เขตลึก 30%) — **ได้ของดีจากฝีมือ ไม่ต้องฟาร์มพันตัว** แก้ปัญหาหลุมดำทรัพยากร

### 4.6 Pouch System

- ของเก็บในแอเรีย → ถุงพกพา ก่อน → กลับฐานโอนเข้ากระเป๋าถาวร
- 1 ชิ้น = 1 ช่อง (ไม่ stack)
- ความจุเริ่ม 12 → +4/ขั้น · 12 ขั้น · สูงสุด 60
- ถุงเต็ม = เก็บเพิ่มไม่ได้ แต่สู้/ไปต่อได้ — **รวมถึงเก็บของเควสไม่ได้ด้วย** (ยอมรับเป็นความเสี่ยงตามธีมความโลภ: เก็บของตัวแทะ/บอสจนเต็มถุงก่อนอาจทำเควสเก็บของไม่ได้)
- ตาย = จบทริป + เสียครึ่ง (ปัดขึ้น) ไม่มีศพให้เก็บคืน
- ไม่เซฟ — ปิดเกมกลางทริป = ของในถุงหาย
- **แผงถุง (B) เปิดได้กลางสนาม เกมเดินต่อ ไม่หยุดเวลา** — ชิดขวาจอ ไม่บังลานกลาง มีคำเตือน "เกมไม่หยุด — ระวังหลัง!"
- ของในแผงอัปเดตสดขณะเปิด · ล็อกไม่ให้เปิดทับมินิเกมผนึก

### 4.7 ระบบเควส (Phase 3E — แก้กฎเควสเก็บของใน Session 4)

**เควสสุ่มใหม่ทุกแมพ** ไม่มีเควสข้ามแอเรีย (ขัดคอนเซปต์แมพสุ่ม)

| ชนิด | เงื่อนไขสำเร็จ |
|---|---|
| collect | **เก็บ "ของกระจายพื้น" (`source === 'ground'`) ให้ครบ** — ปกติ 4 ชิ้น หรือเท่าที่มีจริงถ้าแมพมีของพื้นน้อยกว่า (`quest.collectNeed`) · ของจากตัวแทะ/บอส/กล่องผนึกไม่นับ |
| hunt | ฆ่าบอสให้หมด (กรองออกจากกองสุ่มถ้าแอเรียมี 0 บอส) |
| explore | **เดินเหยียบจุดสำรวจ 2–3 จุดให้ครบ** (สุ่มจำนวน · จุดห่างกันเอง ≥700) |
| seal | แกะกล่องผนึกด้วยมินิเกมแถบจังหวะให้สำเร็จ |

- **ประตูไปต่อปลด 2 ทาง: ทำเควสสำเร็จ หรือ ฆ่าบอสหมด**
- **แอเรีย 0 บอส ไม่ปลดประตูฟรี** — เควสคือทางออก (ประตูกลับฐานเปิดเสมอ ไม่มีการติดกับ)
- จุดที่เหยียบแล้วเปลี่ยนเป็นเขียว + เสาแสงพุ่งฟ้าให้เห็นแต่ไกล
- **กฎตัวนับเควสเก็บของ:** เพิ่ม `quest.collected++` ที่เดียวคือใน `WorldScene.tryPickup()` และเฉพาะเมื่อ `it.source === 'ground'` และเควสปัจจุบันเป็น `collect` เท่านั้น
- เควสเก็บของจะไม่ถูกสุ่มถ้าแมพไม่มีจุดของพื้นเลย · `collectNeed = min(COLLECT_NEED, จำนวนจุด × GROUND_LOOT_PER_SPOT)`

**กฎ Hint (สำคัญ — ห้ามละเมิด):**
- **ห้ามใช้ลูกศรชี้ตรงไปเป้าเควส** (ลูกศรทองใช้ชี้ *ประตู* ที่ปลดแล้วเท่านั้น)
- ใช้ 3 ชั้น: เศษกระดาษโปรยพื้นเป็นทาง · แสงวาบเป็นจังหวะเมื่อใกล้พอ · ข้อความทิศ 8 ทิศ + ระยะเมตร + จำนวนจุดที่เหลือ
- เป้าหมายต้อง "อ่านทิศทางเอง" ไม่ใช่เดินตามลูกศร
- เควสเก็บของ: ข้อความใบ้ชี้เฉพาะ **จุดที่ยังมีของพื้นเหลืออยู่** (`questDirectionHint(..., groundSpots)` รับตำแหน่งจาก `WorldScene.groundItemSpots()`)

**มินิเกมแถบจังหวะ (SealMinigame):**
- เคอร์เซอร์วิ่งไป-กลับ กด E ในช่องทองให้ครบ 2 แผล · พลาดได้ 3 ครั้ง
- พลาดแล้วช่องทองแคบลง ×0.75 และสุ่มตำแหน่งใหม่ (ท่องจังหวะไม่ได้)
- **เกมไม่หยุด** — บอส/ตัวแทะยังตีได้ระหว่างเล่น
- สำเร็จ: ฝาเปิด คายของดี 2 ชิ้น · พัง: ผนึกสะท้อน -1 HP + ของปลอบใจ 1 ชิ้น
- **ห้ามตั้ง `this.minigame = null` ตอนมินิเกมจบใน `update()`** — ให้ callback ตอนจบ (หลังหน่วง 450ms) เป็นคนเคลียร์ ไม่งั้นกด E ซ้ำในช่วงนั้นจะเปิดมินิเกมซ้อน/ได้ของซ้ำ (แก้ใน Session 4)

### 4.8 เลือดข้ามแอเรีย (Session 3 — ยืนยันผลแล้ว)

- **ข้ามแมพไม่ฟื้นเลือด** — เก็บใน `huntSession.tripHP` (ความจำร่วมของทริป ชั้นเดียวกับ pouch)
- ฝากค่าตอน `beginAreaTransition()` · อ่านค่าใน `PlayerActor` constructor
- ล้างค่าเมื่อ: กลับฐานผ่านประตู · ตาย · เริ่มทริปใหม่ → ทริปถัดไปเลือดเต็ม
- **ไม่เซฟลง localStorage** (สอดคล้องกฎ "ปิดเกมกลางทริป = จบทริป")

### 4.9 ระบบเสียง (ใหม่ Session 4 — P1 ✅ ผ่านการทดสอบ)

เสียงสังเคราะห์ด้วย Web Audio ล้วน (ไม่มีไฟล์เสียง) อยู่ใน `src/systems/sfx.ts` ไฟล์เดียว

- **บัสรวม:** master gain → คอมเพรสเซอร์ → ลำโพง กันเสียงซ้อนแล้วแตก
- **ค่าคงที่ปรับระดับเสียง (บนสุดของไฟล์):** `MASTER_VOL` · `AMBIENT_VOL` · `STEP_VOL` · `HEART_VOL` · `TENSION_VOL`
- **บรรยากาศ:** ลมกระดาษวนตลอดทริป (นอยส์ชมพู + LFO) + เสียงกระดาษขยับสุ่ม 2.5–9 วิ + เสียงทุ้มตึงเครียดที่เปิดเฉพาะตอนสู้บอส · เริ่มใน `WorldScene.create()` · หยุดตอน SHUTDOWN / ตาย / กลับฐาน
- **เสียงเท้า:** `WorldScene.updateAudio()` อ่านชนิดแผ่นพื้นใต้เท้า (`dirt / moss / gravel / sand / brush`) ก้าวละ `STEP_DIST = 46` px · แดช (ความเร็ว ≥260) ไม่มีเสียงเท้า
- **หัวใจเต้น:** เลือด ≤ `LOW_HP_RATIO = 0.34` ยิ่งเลือดน้อยยิ่งถี่/ดัง
- **เสียงจังหวะสำคัญ:** `bossWake` · `setTension` · `pickupRarity(rarity)` · `questDone` · `gateUnlock` · `shrineStart/Tick/Break` · `sealBreak/Backfire` · `minionLunge/Die` · `whoosh` · `death` · `homeward`
- ชื่อเดิม `swing / hit / hurt / dash / open / pickup / warn / bossDie / toggleMute` ยังใช้ได้ตามเดิม
- ปิดเสียง (M) หยุดลมพื้นหลังด้วย เปิดใหม่ลมกลับมาเอง · พับแท็บเสียงหยุดอัตโนมัติ
- ยังไม่ได้จูนรสนิยมเสียงเชิงลึก — ปรับที่ค่าคงที่ หรือแก้ฟังก์ชันเสียงรายตัว

### 4.10 กฎสี/แฟลชของ Phaser 4 (ใหม่ Session 4 — P2 ✅ ผ่านการทดสอบ)

ตรวจจากตัว Phaser 4.2.1 จริงแล้ว:

- `setTintFill()` **ถูกถอด** — เรียกแล้วแค่พิมพ์ error ลง Console ไม่ทำอะไร → **ห้ามใช้**
- แฟลชทึบ = `sprite.setTint(สี).setTintMode(Phaser.TintModes.FILL)` (`FILL = 1`; ถ้าคอมไพล์ไม่รู้จัก `Phaser.TintModes` ให้ใช้เลข `1`)
- `setTint(0xffffff)` ในโหมดปกติ (คูณสี) **ไม่เห็นผลอะไร** — ไม่ใช่แฟลช
- **กับดัก:** `setTint()` ไม่รีเซ็ตโหมด มีแต่ **`clearTint()` ที่รีเซ็ตกลับเป็นโหมดคูณ** → ทุกจุดคืนสีหลังแฟลชต้องเรียก `clearTint()` ก่อนเสมอ แล้วค่อย `setTint(สีฐาน)` ถ้ามี (ไม่งั้นสไปรต์ค้างเป็นแผ่นสีทึบ)
- จุดที่ใช้แล้ว: ผู้เล่นโดนตี (แดง) · ผู้เล่นโดนไฟ (ส้ม) · บอสโดนตี (ขาว) · ตัวแทะโดนตี (ขาว)
- `PlayerActor.applyBaseTint()` ข้ามถ้าตายแล้ว (ไม่ทับสีเทาท่าตาย) และท่าตายต้อง `clearTint()` ก่อนตั้งสีเทา

- ร่างปลอมของมายาใช้ออฟเซตสลับทิศ (`SHADOW_DX_FAKE = -7`) เป็น **เบาะแส gameplay — ห้ามทำลาย**
- ชั้นความลึกใช้ค่าคงที่ `DEPTH.*` ใน `src/config.ts` (`PLAYER_SHADOW`, `ENEMY_SHADOW`, `ENEMY`, `TELEGRAPH`, `HUD` ฯลฯ)
- มีฟังก์ชัน `makeVignette` ใน `systems/effects.ts` อยู่แล้ว
- ทิศแสงตามสไตล์: **ซ้ายบน → เงาขวาล่าง**

**ขอบเขตที่เสนอ (แบ่งเป็นก้อนเล็ก ทำทีละก้อน ทดสอบก่อนต่อ):**
1. **P3a ระบบเงารวมศูนย์** — ค่าคงที่ทิศแสงที่เดียว (เช่น `LIGHT` ใน config) + ฟังก์ชันสร้าง/ขยับเงากลาง ให้ทุก Entity ใช้ออฟเซตจากที่เดียว (เงาเอียงตามทิศแสง ยาวตามขนาดตัว) · ร่างปลอมมายาใช้ทิศตรงข้ามจากค่าเดียวกัน
2. **P3b แสงอำพันจุดสำคัญ** — แสงเรืองนุ่มที่ประตูที่ปลดแล้ว · เสาฟื้น · กล่องผนึก · จุดเควส · ของหายาก (ภาพวงกลมไล่สี + blend แบบบวก + เต้นช้า ๆ) — ต้องตรงสไตล์สี: เขียว = สำเร็จ/ฟื้น · ทอง = เป้าหมาย/รางวัล · แดงส้ม = อันตราย
3. **P3c ฝุ่นกระดาษลอย** — อนุภาคน้อย ๆ ลอยช้าในแมพ (จำนวนจำกัดเพื่อประสิทธิภาพ) ไม่บังการอ่านสนาม
4. **P3d (ทางเลือก) โทนสีตามเขต** — เขตตื้นอบอุ่น → เขตลึกเย็น/มืดขึ้น ผูกกับ `DepthTier` (ถ้าอนุมัติ)

**ความเสี่ยง/สิ่งที่ต้องตรวจก่อนเขียนโค้ด:**

## 7. AI Workflow Rules

- หนึ่ง Prompt = หนึ่ง Feature
- ก่อนแก้โค้ด: สรุปแผน 2–4 ประโยค + ไฟล์ที่จะแก้ + ความเสี่ยง
- รออนุมัติก่อนเปลี่ยนโค้ดเดิม
- หลังแก้: บอกวิธีรันและทดสอบเป็นขั้นตอน (เช็กลิสต์สั้น ๆ ตรวจได้จริง)
- ห้ามลบระบบที่ทำงานได้โดยไม่ตรวจผู้เรียก
- **ห้ามแก้ Gameplay + Art พร้อมกัน**
- ห้ามสมมติ Asset มีอยู่จริง — ตรวจ `public/assets` ก่อน
- ใช้ `setTexture()` สำหรับ Animation
- ห้ามเพิ่ม Library ถ้า Phaser/TS ทำได้
- ส่งโค้ดเป็นไฟล์เต็ม หรือ search+replace ที่ชัด (ระบุ "หา" / "แทนที่ด้วย" และบอกว่าแทนที่แค่ไหน)
- ห้ามอ้างว่าทดสอบแล้วถ้าไม่ได้รันจริง — ถ้าตรวจจากการอ่านโค้ดอย่างเดียว ให้บอกตรง ๆ
- **API ของ Phaser 4 ต้องตรวจกับตัวไลบรารีจริงก่อนใช้** (ติดตั้ง `phaser@4.2.1` ในที่ทำงานแล้วค้นซอร์ส) ไม่ใช้ความจำของ v3
- ตรวจ error ก่อน: F12 → Console + `npx tsc --noEmit`
- จอดำ = ดู Console + Terminal `npm run dev`
- VS Code บน Windows Local เท่านั้น
- **Repomix มีอักขระเพี้ยนจากการแพ็ก** (`expor t`, `prote cted`, `> > >`, `/* ... /`) — อ่านข้ามจุดเพี้ยนได้ แต่ห้ามคัดลอกข้อความเพี้ยนกลับไปเป็นโค้ดจริง

## 9. Style Guide — Paper Cutout

- Art: Paper Cutout / Layered Diorama
- Camera: Top-down
- Palette: น้ำตาลดิน, เขียวมอส, เหลืองอำพัน, แสงเรืองรอง
- Material: กระดาษด้าน มีเส้นใย
- Light: **ซ้ายบน → เงาขวาล่าง** (ยึดทิศนี้ทุกตัว รวมตัวแทะและเสาฟื้น)
- เงาผิดทิศ: เฉพาะร่างปลอมของมายา เท่านั้น (เป็นเบาะแส gameplay)
- สีเขียว `0x7dff9b` = สำเร็จ/ฟื้น/ปลอดภัย · ทอง `0xffd166` = เป้าหมาย/รางวัล · แดงส้ม `0xff5a3a` = อันตราย
- เสียง: โทนกระดาษ/ลม/ไม้ นุ่ม ไม่แหลมบาด — เสียงหรูขึ้นตามระดับหายากของของที่เก็บ

- **(Session 4) เควสเก็บของนับเฉพาะของพื้น** + แพตช์บั๊กร่วม (มินิเกมซ้อน · ตายระหว่างเฟด · collectNeed · ใบ้ชี้จุดที่เหลือ) ผ่านการทดสอบ

### ⏳ ค้าง / หนี้ที่รู้แล้ว

| รายการ | ความรุนแรง | หมายเหตุ |
|---|---|---|
| ตายแล้วรีเฟรชหน้าเว็บ = ได้ของครึ่งที่เหลือฟรี | 🟠 | ตรวจ `Pouch.resolveDeath()` / `saveGame()` แล้วยังไม่เห็นช่องโหว่ชัดเจน (ตายแล้วโอนครึ่งที่เหลือเข้ากระเป๋าถาวรตามที่ออกแบบ · ถุงกลางทริปไม่เซฟ) — **ต้องการขั้นตอนทำซ้ำจากผู้เล่น** ว่าเห็นของเพิ่มจากอะไร |
| ผนึกพัง + แมพ 0 บอส = ประตูไปต่อไม่เปิด (ต้องกลับฐาน) | 🟡 | ตรงกับสเปก "ไม่ติดกับ" แต่อาจรู้สึกโหดเกิน — **เป็นการตัดสินใจดีไซน์ รอผู้พัฒนา** |
| ตัวเลข/ค่าฝังในโค้ด | 🟡 | `HITS_NEEDED = 2` ใน SealMinigame.ts · โอกาส legendary `0.12` ใน WorldScene · `SEAL.pityCount` ประกาศแล้วแต่ไม่ถูกใช้ (โค้ดคายของปลอบใจ 1 ชิ้นแบบฝังเลข) — ควรย้ายเข้า `data/` |
| GameScene canvas click listener ไม่ถอด | 🟡 | สะสมทุกครั้งที่ restart (WorldScene แก้แล้ว) |
| มินิแมป fog + ร่องรอยรัง | 🟡 | 3F ที่เหลือ |
| Seamless zoom | 🟡 | ตอนนี้ tween ธรรมดา ยังไม่ seamless |
| แฟลช/สีอื่นที่ยังใช้ `setTint` แบบคูณ | 🟢 | ลูกเล่นกระพริบของบอส (ม่วง/แดง/เหลือง) และสีเดือดยังใช้โหมดคูณ — ใช้ได้ แต่ถ้าอยากให้ทึบเหมือนแฟลชให้ทำตามกฎ 4.10 |
| คอมเมนต์มีคำภาษาอื่นปน | 🟢 | หลายไฟล์จาก Session 3 — แก้เป็นไทยล้วนเมื่อแตะไฟล์นั้น |
| บาลานซ์ระยะยาว | 🟡 | ยังไม่ผ่านการเล่นจริงหลายทริปติด |
| จุดเดิมพันกลางแอเรีย (แบบ 2) | ⏳ | อนุมัติแนวคิดแล้ว ยังไม่สร้าง |
| คอมเมนต์ `dropChance` ใน `data/minions.ts` | 🟢 | ยังเขียนว่า "ให้อาหารเควสเก็บของ" ซึ่งไม่จริงแล้ว — ตัดท่อนนั้นออกเมื่อแตะไฟล์ |

### Do not

- ใช้ Points · Pop-up อัปเกรด/กระเป๋า · Backtracking/Chunk Streaming · ต่อท่อห้อง/edge-matching
- โชว์สูตรคูณในหน้าอัปเกรด · ตัดเควสออกจากแอเรีย
- ใช้ `GAME_WIDTH/HEIGHT` หรือ `WORLD_*` ภายในแอเรีย (ใช้ `physics.world.bounds`)
- **ลูกศรชี้ตรงไปเป้าเควส** (ลูกศรทองชี้ประตูที่ปลดแล้วเท่านั้น)
- **เควสข้ามแอเรีย / ของฝากข้ามแมพ** (ขัดคอนเซปต์แมพสุ่ม)
- **ฟื้นเลือดอัตโนมัติตอนข้ามแมพ**
- แก้ BaseScene เป็น Open World (ยังไม่อนุมัติ — รอ Phase 4)
- เปลี่ยน Phaser Version · ลบ Asset เดิม
- แก้ `WorldScene.ts` หรือ `AreaBosses.ts` เพื่อรองรับบอสใหม่ — ใช้ Registry Pattern
- สร้าง `CombatTarget` ใหม่ทุกเฟรม
- **เรียก `setTintFill()`** (ถูกถอดใน Phaser 4) · **คืนสีหลังแฟลชด้วย `setTint()` โดยไม่เรียก `clearTint()` ก่อน**
- **เพิ่มตัวนับเควสเก็บของนอก `tryPickup`** หรือนับของที่ `source` ไม่ใช่ `'ground'`
- **สร้าง `DroppedItem` ใน WorldScene โดยไม่ระบุ `source`**
- **ตั้ง `this.minigame = null` ตอนมินิเกมจบใน `update()`**
- **สร้าง `AudioContext` นอก `sfx.ts`**
- แก้ Gameplay/สมดุลระหว่างทำ P3 (Art) — แยกคนละรอบ
