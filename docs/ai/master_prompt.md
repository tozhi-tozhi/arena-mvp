คุณคือ Game Director + Technical Partner ของโปรเจกต์นี้

- Developer เป็น Solo Developer ที่ไม่มีพื้นฐานเขียนโค้ด ใช้ AI เป็นเครื่องมือหลัก

Phase 1: Single-player playable          [DONE]
   v
Phase 2: Content + progression           [2A DONE]
   v
Phase 3: The World (Area-based)          [3A–3F ✅ ปิดครบแล้วใน Session 5]

   v
Phase 4: Base เดินเล่นได้จริง             [✅ ปิดแล้วใน Session 5 — ฐานเดินได้ · ห้องแต่งตัว · สมุดบันทึก]
   v
Phase 4B: เก็บงานฐาน (ทางเลือก)          [⏳ ตัวชนเฟอร์นิเจอร์ · แยกโทนเสียงฐาน · ธง/ป้ายเพิ่ม]
   v
Phase 5: Local co-op / Online            [OPTIONAL, NOT IN SCOPE]

กฎหลัก:

- อย่าออกแบบ Multiplayer จนทำให้ Single-player ซับซ้อน
- แยกความรับผิดชอบของ Scene, Entity, System, Data, UI ให้ชัดเจน
- **ตัวเลขปรับสมดุลต้องอยู่ในไฟล์ Data ไม่กระจายใน Scene** (มีหนี้ค้าง — ดูหัวข้อ 11)
- ใช้ระบบที่มีอยู่ซ้ำก่อนสร้างระบบใหม่
- ตัวเลขสมดุลของอัปเกรด/ดาว → `Upgrades.ts` ที่เดียว ทั้ง UI และเกมต่อสู้อ่านจากฟังก์ชันเดียวกัน
- **เพิ่มบอสใหม่ → แก้ 3 ไฟล์เท่านั้น:** `bosses.ts` (ชื่อ), `createBoss.ts` (Registry), `BossLoader.ts` (Asset) — `WorldScene.ts` และ `AreaBosses.ts` ห้ามแตะ
- **เพิ่มมอนสเตอร์เดินสุ่มชนิดใหม่ → ใช้ `CombatTarget` เดิม** ห้ามแก้ `PlayerActor.ts` (พิสูจน์แล้วกับตัวแทะกระดาษ)
- ห้ามทำ Backtracking / Chunk Streaming — แอเรียเก่าทิ้งได้ มีประตูวาปกลับฐาน
- **ของที่สร้างทุกเฟรมต้องแคช**: `CombatTarget` สร้างครั้งเดียวตอน spawn ห้ามสร้างใน `getTargets()` (บทเรียนบั๊ก multi-hit)
- **ภาพนิ่ง/ของตกแต่งต้อง bake เป็น texture ครั้งเดียว** then วางเป็น image — ห้ามวาด Graphics ใหม่ทุกแผ่นทุกเฟรม (`areaTextures.ts` · `itemIcons.ts` · `baseTextures.ts` · `minionTextures.ts` ใช้แบบเดียวกันหมด มีตัวกันวาดซ้ำด้วย `textures.exists`)
- ทุก Entity ต้องมี `destroy()` ที่ไม่ดรอปของ ไม่เรียก `onDeath` — ใช้ตอนล้างแอเรีย
- **ของตกพื้นทุกชิ้นต้องระบุ `source` ตอนสร้าง `DroppedItem`** (`'ground' | 'minion' | 'boss' | 'seal' | 'other'`) — ถ้าไม่ระบุจะได้ `'other'` ซึ่งไม่นับเควสเก็บของ
- **เสียงใหม่ทุกตัวเพิ่มใน `src/systems/sfx.ts` ที่เดียว** ห้ามสร้าง `AudioContext` เองที่อื่น · ระดับเสียงปรับที่ค่าคงที่บนสุดของไฟล์
- **เงา/แสงใช้ระบบกลางเท่านั้น** — ดูหัวข้อ 4.13
- **กฎ Phaser 4 เรื่องสี/แฟลช (บังคับ):** ดูหัวข้อ 4.10
- **กฎ UI + TypeScript ที่พลาดจริง:** ดูหัวข้อ 4.14

### 4.2 Boss Design Rules

- บอสทุกตัวต้องมีเอกลักษณ์ ห้ามแค่เพิ่ม HP/Damage
- Telegraph ต้องบอกพื้นที่/ทิศทางอันตราย
- ช่วง Rage ต้องเปลี่ยนรูปแบบการเล่น
- ระยะ/ขอบเขตทั้งหมดอิง `physics.world.bounds` ของแอเรียปัจจุบัน
- บอสเกิดในสภาพ `setSleeping(true)` — ตื่นเมื่อผู้เล่นเข้าใกล้ `DETECT_RADIUS = 500` **ทีละตัว**
- ตัวที่ยังหลับ: ผู้เล่นตีไม่ได้ ครกจิ๋วไม่ยิงใส่ ไม่ปลุกตัวข้างเคียง
- เลือดบอสใน The World = เลือดฐาน × `hpMult` ของเขต (ห้องฝึกไม่คูณ) — `def` ถูก clone ใน `BossBase` แล้ว จึงไม่รั่วข้ามฉาก
- ดาเมจขาออกคูณที่ `bossHooks.onHitTarget` จุดเดียว ผ่าน `scaleBossDamage()` (`Math.round`, ขั้นต่ำ 1)
- ไฟไหม้คูณที่ `bossHooks.onBurn` ด้วย `burnMult` ของเขต
- **บอสตายใน The World เรียก `huntSession.addBossKill()`** (สถิิติในสมุดบันทึก) — ห้องฝึกไม่นับ

บอสที่มีอยู่:
- **ภัสมะ (Phasama)** — ตัวนิ่มลาวา: ไล่, พ่นไฟกรวยหมุน, พุ่งชน, คลั่งหมุนลูกข่าง มีมึนให้ตีกลับ (เลือดฐาน 80)

### 4.3 Character Design Rules

- Sprite หันขวาเสมอ → โค้ด FlipX
- ระยะ/ขอบเขตทั้งหมดเทียบกับ `physics.world.bounds` ไม่ใช่ `WORLD_WIDTH/HEIGHT` หรือ `GAME_WIDTH/HEIGHT`
- การเล็งใช้ `cam.getWorldPoint()` (มี fallback สูตรซูม) — ห้ามกลับไปใช้ `pointer + scrollX` ตรง ๆ

| Character | Playstyle | Normal | Charged | Skill | Passive | HP |
|---|---|---|---|---|---|---|
| อัคนี | ประชิด/ฟันกวาด | ฟันสั้น | ฟัน+พุ่งดาบ | ฟันใหญ่ + อมตะ + ฟื้นเลือด | โดนตีจริงได้โล่ 1 ฮิต | 6 |

ประตูสาธารณะของ PlayerActor ที่ฉากเรียกได้: `get hp()`, `heal(n)`, `takeDamage()`, `applyBurn()`, `setVictory()`, `endEncounter()`, `hitStop()`

**ข้อจำกัดที่รู้แล้ว:** PlayerActor ไม่ได้เปิดทิศเล็ง (`facing` เป็น private) → ลูกศรบนแผนที่ใช้ **ทิศการเดินจาก velocity** แทน ไม่ใช่ทิศเมาส์ ถ้าจะให้ชี้ตามเมาส์ต้องเพิ่ม getter อ่านอย่างเดียว (ยังไม่ทำ)

### 4.4 มอนสเตอร์เดินสุ่ม + จุดฟื้นเลือด

**ตัวแทะกระดาษ (Minion)** — ทำให้แมพมีชีวิต ไม่ใช่แค่ของวางพื้น
- เป็น "สีสันและความเสี่ยงเล็ก" **ไม่ใช่กำแพงความยาก** — ตัวเบา เดินหนีทันเสมอ
- ตื่นเสมอ (ไม่ใช้ระบบ sleep แบบบอส) แต่ไล่เมื่อเข้าใกล้ 260 เท่านั้น
- วงจร: เดินสุ่มรอบบ้าน → ไล่ → ง้าง (วงเตือน 430ms) → พุ่ง → นิ่งเปิดให้ตี → เลิกไล่กลับบ้านเมื่อผู้เล่นห่าง 720
- ตายคายของ 1 ชิ้นเสมอ (เรทตามเขต) → เป็นแหล่งความโลภ/ทรัพยากร **แต่ไม่นับเป็นความคืบหน้าเควสเก็บของ**
- **เลือดคงที่ 3 ทุกเขต ไม่คูณตามความลึก** (ตั้งใจ — บอสเป็นตัวแบกเส้นความยาก)
- ไม่นับเป็นเงื่อนไขปลดประตู

**เสาฟื้นเลือด (HealShrine)** — จุดพักที่มีราคา
- สุ่ม 0–2 จุดต่อแมพ (บางแมพไม่มี = ต้องบริหารเลือด)
- กด E แล้วยืนฟื้น **ทีละ 1 หน่วยทุก 600ms** ไม่ใช่ปุ่มฟรี
- หยุดฟื้นเมื่อ: เดินออกนอก 95px · **เลือดลดจากภายนอก (โดนตี)** · เลือดเต็ม · จบทริป
- มีตัวแทะเฝ้า 1 ตัวต่อจุดโดยตั้งใจ — การพักมีความเสี่ยงของตัวเอง

### 4.6 Pouch System

- ของเก็บในแอเรีย → ถุงพกพา ก่อน → กลับฐานโอนเข้ากระเป๋าถาวร
- 1 ชิ้น = 1 ช่อง (ไม่ stack)
- ความจุเริ่ม 12 → +4/ขั้น · 12 ขั้น · สูงสุด 60
- ถุงเต็ม = เก็บเพิ่มไม่ได้ แต่สู้/ไปต่อได้ — **รวมถึงเก็บของเควสไม่ได้ด้วย** (ยอมรับเป็นความเสี่ยงตามธีมความโลภ)
- ตาย = จบทริป + เสียครึ่ง (ปัดขึ้น) ไม่มีศพให้เก็บคืน
- ไม่เซฟ — ปิดเกมกลางทริป = ของในถุงหาย
- **แผงถุง (B) เปิดได้กลางสนาม เกมเดินต่อ ไม่หยุดเวลา** — ชิดขวาจอ ไม่บังลานกลาง มีคำเตือน "เกมไม่หยุด — ระวังหลัง!"
- ของในแผงอัปเดตสดขณะเปิด · ล็อกไม่ให้เปิดทับมินิเกมผนึก

### 4.7 ระบบเควส

**เควสสุ่มใหม่ทุกแมพ** ไม่มีเควสข้ามแอเรีย (ขัดคอนเซปต์แมพสุ่ม)

| ชนิด | เงื่อนไขสำเร็จ |
|---|---|
| collect | **เก็บ "ของกระจายพื้น" (`source === 'ground'`) ให้ครบ** — ปกติ 4 ชิ้น หรือเท่าที่มีจริงถ้าแมพมีของพื้นน้อยกว่า (`quest.collectNeed`) · ของจากตัวแทะ/บอส/กล่องผนึกไม่นับ |
| hunt | ฆ่าบอสให้หมด (กรองออกจากกองสุ่มถ้าแอเรียมี 0 บอส) |
| explore | **เดินเหยียบจุดสำรวจ 2–3 จุดให้ครบ** (สุ่มจำนวน · จุดห่างกันเอง ≥700) |
| seal | แกะกล่องผนึกด้วยมินิเกมแถบจังหวะให้สำเร็จ |

- **ประตูไปต่อปลด 2 ทาง: ทำเควสสำเร็จ หรือ ฆ่าบอสหมด**
- **แอเรีย 0 บอส ไม่ปลดประตูฟรี** — เควสคือทางออก (ประตูกลับฐานเปิดเสมอ ไม่มีการติดกับ)
- จุดที่เหยียบแล้วเปลี่ยนเป็นเขียว + เสาแสงพุ่งฟ้าให้เห็นแต่ไกล + ดับแสงอำพันของจุดนั้น
- **กฎตัวนับเควสเก็บของ:** เพิ่ม `quest.collected++` ที่เดียวคือใน `WorldScene.tryPickup()` และเฉพาะเมื่อ `it.source === 'ground'` และเควสปัจจุบันเป็น `collect` เท่านั้น
- เควสเก็บของจะไม่ถูกสุ่มถ้าแมพไม่มีจุดของพื้นเลย · `collectNeed = min(COLLECT_NEED, จำนวนจุด × GROUND_LOOT_PER_SPOT)`

**กฎ Hint (สำคัญ — ห้ามละเมิด):**
- **ห้ามใช้ลูกศรชี้ตรงไปเป้าเควส** (ลูกศรทองใช้ชี้ *ประตู* ที่ปลดแล้วเท่านั้น)
- ใช้ 3 ชั้น: เศษกระดาษโปรยพื้นเป็นทาง · แสงวาบเป็นจังหวะเมื่อใกล้พอ · ข้อความทิศ 8 ทิศ + ระยะเมตร + จำนวนจุดที่เหลือ
- **แผนที่กระดาษไม่ทำลายกฎนี้** — แสดงเฉพาะจุดที่ "เดินเคยเห็นแล้ว" (อยู่ในหมอกที่เปิด) ผู้เล่นต้องออกไปหาเองก่อน แผนที่ไม่เคยเปิดหมอกจะไม่บอกอะไรเลย
- เป้าหมายต้อง "อ่านทิศทางเอง" ไม่ใช่เดินตามลูกศร
- เควสเก็บของ: ข้อความใบ้ชี้เฉพาะ **จุดที่ยังมีของพื้นเหลืออยู่** (`questDirectionHint(..., groundSpots)`)

**มินิเกมแถบจังหวะ (SealMinigame):**
- เคอร์เซอร์วิ่งไป-กลับ กด E ในช่องทองให้ครบ 2 แผล · พลาดได้ 3 ครั้ง
- พลาดแล้วช่องทองแคบลง ×0.75 และสุ่มตำแหน่งใหม่ (ท่องจังหวะไม่ได้)
- **เกมไม่หยุด** — บอส/ตัวแทะยังตีได้ระหว่างเล่น
- สำเร็จ: ฝาเปิด คายของดี 2 ชิ้น · พัง: ผนึกสะท้อน -1 HP + ของปลอบใจ 1 ชิ้น
- **ห้ามตั้ง `this.minigame = null` ตอนมินิเกมจบใน `update()`** — ให้ callback ตอนจบ (หลังหน่วง 450ms) เป็นคนเคลียร์

### 4.8 เลือดข้ามแอเรีย

- **ข้ามแมพไม่ฟื้นเลือด** — เก็บใน `huntSession.tripHP` (ความจำร่วมของทริป ชั้นเดียวกับ pouch)
- ฝากค่าตอน `beginAreaTransition()` · อ่านค่าใน `PlayerActor` constructor

- **ไม่เซฟลง localStorage** (สอดคล้องกฎ "ปิดเกมกลางทริป = จบทริป")
- ห้องฝึกไม่กระทบ — ไม่ได้ฝากค่า จึงเต็มเสมอ

### 4.9 ระบบเสียง (P1 ✅)

เสียงสังเคราะห์ด้วย Web Audio ล้วน (ไม่มีไฟล์เสียง) อยู่ใน `src/systems/sfx.ts` ไฟล์เดียว

- **บัสรวม:** master gain → คอมเพรสเซอร์ → ลำโพง กันเสียงซ้อนแล้วแตก
- **ค่าคงที่ปรับระดับเสียง (บนสุดของไฟล์):** `MASTER_VOL` · `AMBIENT_VOL` · `STEP_VOL` · `HEART_VOL` · `TENSION_VOL`
- **บรรยากาศ:** ลมกระดาษวนตลอดทริป (นอยส์ชมพู + LFO) + เสียงกระดาษขยับสุ่ม 2.5–9 วิ + เสียงทุ้มตึงเครียดที่เปิดเฉพาะตอนสู้บอส
- **เสียงเท้า:** `WorldScene.updateAudio()` อ่านชนิดแผ่นพื้นใต้เท้า (`dirt / moss / gravel / sand / brush`) ก้าวละ `STEP_DIST = 46` px · แดช (ความเร็ว ≥260) ไม่มีเสียงเท้า
- **หัวใจเต้น:** เลือด ≤ `LOW_HP_RATIO = 0.34` ยิ่งเลือดน้อยยิ่งถี่/ดัง
- **เสียงจังหวะสำคัญ:** `bossWake` · `setTension` · `pickupRarity(rarity)` · `questDone` · `gateUnlock` · `shrineStart/Tick/Break` · `sealBreak/Backfire` · `minionLunge/Die` · `whoosh` · `death` · `homeward`
- ชื่อเดิม `swing / hit / hurt / dash / open / pickup / warn / bossDie / toggleMute` ยังใช้ได้
- ปิดเสียง (M) หยุดลมพื้นหลังด้วย เปิดใหม่ลมกลับมาเอง · พับแท็บเสียงหยุดอัตโนมัติ
- **ฐานเรียก `sfx.startAmbient()` + `setTension(false)` เอง** และหยุดตอน SHUTDOWN · ปุ่ม M ในฐานทำงานแล้ว (Session 5)
- **หนี้ที่รู้:** เสียงลมในฐานยังใช้ชุดเดียวกับ The World — ยังไม่ได้แยกโทนให้ต่างบรรยากาศ
- แผนที่กระดาษใช้เสียงเดิม: สลับขนาด = `sfx.open()` · พบรังบอส = `sfx.warn()` · พบเสา/กล่อง/จุดสำรวจ = `sfx.pickup()` (ไม่สร้างเสียงใหม่)

### 4.10 กฎสี/แฟลชของ Phaser 4 (P2 ✅ — บังคับ)

ตรวจจากตัว Phaser 4.2.1 จริงแล้ว:

- `setTintFill()` **ถูกถอด** — เรียกแล้วแค่พิมพ์ error ลง Console ไม่ทำอะไร → **ห้ามใช้**
- แฟลชทึบ = `sprite.setTint(สี).setTintMode(Phaser.TintModes.FILL)` (`FILL = 1`; ถ้าคอมไพล์ไม่รู้จัก `Phaser.TintModes` ให้ใช้เลข `1`)
- `setTint(0xffffff)` ในโหมดปกติ (คูณสี) **ไม่เห็นผลอะไร** — ไม่ใช่แฟลช
- **กับดัก:** `setTint()` ไม่รีเซ็ตโหมด มีแต่ **`clearTint()` ที่รีเซ็ตกลับเป็นโหมดคูณ** → ทุกจุดคืนสีหลังแฟลชต้องเรียก `clearTint()` ก่อนเสมอ แล้วค่อย `setTint(สีฐาน)` ถ้ามี
- จุดที่ใช้แล้ว: ผู้เล่นโดนตี (แดง) · ผู้เล่นโดนไฟ (ส้ม) · บอสโดนตี (ขาว) · ตัวแทะโดนตี (ขาว)
- `PlayerActor.applyBaseTint()` ข้ามถ้าตายแล้ว และท่าตายต้อง `clearTint()` ก่อนตั้งสีเทา
- **ข้อยกเว้นที่ใช้โหมดคูณได้:** วงจุดใช้งานในฐานย้อมสีด้วย `ring.setTint(def.color)` (ภาพขาว bake ไว้แล้ว ย้อมเป็นสีจุด) — ไม่ต้อง FILL และไม่ต้อง clearTint เพราะไม่เคยตั้งโหมด FILL

**หลักการ:** เป็นเครื่องมือ "รับรู้พื้นที่" ไม่ใช่ลูกศรชี้เป้า — เปิดหมอกด้วยการเดินเท่านั้น

- ไฟล์: `src/systems/HuntMinimap.ts` (ตรรกะ+วาด) · `src/data/minimap.ts` (ตัวเลข/สีทั้งหมด)
- **วาดด้วย Graphics 4 ชั้น** ไม่ใช้ RenderTexture/Container:
  1. พื้นแผนที่ — วาดครั้งเดียว สีแผ่นจริงจาก `TILE_KINDS` + วงลานกลาง + ขอบแอเรีย
  2. หมอก — วาดใหม่ทุก `redrawMs = 66` (รวมช่องสถานะเดียวกันเป็นแถบเดียวแบบ run-length → เหลือ ~80 สี่เหลี่ยมแทน 520)
  3. ร่องรอย + เครื่องหมาย — วาดใหม่จังหวะเดียวกัน
  4. ลูกศรผู้เล่น — **วาดทุกเฟรม** (ลื่นเวลาหัน)
- หมอก 3 สถานะ: ยังไม่เคยเดิน = ทึบ (`fogAlpha 0.93`) · เคยเดินแต่ไม่อยู่แถวนี้ = หรี่ (`dimAlpha 0.42`) · ในรัศมีมองเห็น = สว่าง
- ตารางหมอก 26×20 ช่อง · รัศมีเปิด 620px ในโลก · % สำรวจแสดงบนหัวแผง
- **ร่องรอยทางที่เดิน:** โปรยจุดทุก 240ms เมื่อเดินห่างจุดเดิม ≥55px เก็บสูงสุด 300 จุด วาดเป็นเส้นทอง 4 ช่วงอายุ (ใหม่ชัด เก่าจาง)
- **ร่องรอยรัง:** พบบอสครั้งแรก (เดินเข้าใกล้จนหมอกเปิด) → จดตำแหน่งไว้ทั้งทริปเป็นสามเหลี่ยมแดง **ค้างแม้เดินห่าง/หมอกปิดทับ** · บอสตายแล้วเปลี่ยนเป็นขีดฆ่าเทา
- เครื่องหมายอื่น (เฉพาะที่เดินเคยเห็น): เสาฟื้น = กากบาทเขียว · กล่องผนึก = เหลี่ยมทอง (จบแล้วจาง) · จุดสำรวจ = วงครีม → กากบาทเขียวเมื่อพบ · ของพื้นยังไม่เก็บ = จุดฟ้า
- **ประตูกลับฐานเห็นเสมอตั้งแต่เริ่ม** (ทางกลับบ้านไม่มีวันหลง) · ประตูไปต่อเห็นเป็นเหลี่ยมเทาเมื่อล็อก → ทองเต้นเมื่อปลด
- 3 ขนาด: เต็ม (มีคำอธิบายสัญลักษณ์ + แถวบอกสิ่งที่พบ) → เล็ก → ปิด (เหลือปุ่ม `[Q] แผนที่`)
- **ไม่เซฟลงเครื่อง** — จบแอเรีย = จบแผนที่ (สอดคล้องกฎแมพสุ่ม)
- อยู่ชั้น `DEPTH.HUD - 1` → ลูกศรนำทางประตู/แผงถุง/มินิเกมผนึก วาดทับได้ ไม่บังกัน
- เป็น UI ติดจอ (`setScrollFactor(0)`) → `UiCamera` แยกไปกล้อง UI อัตโนมัติ **ไม่โตตามซูมตอนสู้บอส**

**ซูมกล้องต่อเนื่อง (Seamless zoom ✅)**
- เลิกใช้ `cam.zoomTo()` แบบ tween → ใช้ `targetZoom` + `updateCameraZoom(delta)` หน่วงแบบ `1 - Math.exp(-delta / 260)`
- ค่าคงที่ใน WorldScene: `ZOOM_COMBAT = 0.75` · `ZOOM_NORMAL = 1` · `ZOOM_DAMP_MS = 260`
- ข้อดี: ไม่มี tween ชนกันเวลาสลับบอส/ตายกลางซูม · `tripEnded || actor.isDead` บังคับเป้าหมายกลับ 1 เสมอ กล้องไม่ค้างซูม

### 4.13 กฎเงา/แสงรวมศูนย์ (P3a + P3b ✅ — บังคับ)

**เงา (P3a)**
- ทิศแสงอยู่ที่เดียว: `LIGHT` ใน `src/config.ts` → `DIR_X 1 · DIR_Y 1 · OFFSET_X 6 · OFFSET_Y 4` (แสงซ้ายบน → เงาขวาล่าง)
- สร้างเงาด้วย `makeShadow(scene, width, height, depth, alpha)` · ขยับด้วย `syncShadow(shadow, sprite, groundOffsetY?, isFake?, customOffsetY?)`
- **ห้าม Entity คำนวณออฟเซตเงาเอง** — ผู้เล่น/บอส/ตัวแทะ/เสาฟื้น ใช้ระบบกลางหมดแล้ว
- `isFake = true` กลับทิศจาก `LIGHT` ค่าเดียวกัน → เบาะแสร่างปลอมมายายังอยู่ และแก้ทิศแสงทั้งเกมได้ที่จุดเดียว
- ของตกแต่งนิ่ง (เสา/กล่อง/ของในฐาน) **bake เงาลงใน texture** โดยเยื้องด้วย `LIGHT.OFFSET_*` → ทิศตรงกับระบบกลาง แต่ไม่ต้องมีวัตถุเงาแยก

**แสงจุดสำคัญ (P3b)**
- `makeGlow(scene, x, y, radius, color, pulse)` → วงกลม 2 ชั้น blend ADD เต้นช้า · อยู่ชั้น `DEPTH.TELEGRAPH - 1` (เหนือพื้น ใต้ Telegraph → **ไม่บังวงเตือนบอส**)
- **ต้องเรียก `destroyGlow(glow)` คู่กับ every destroy** — จุดที่ใช้: ประตูไปต่อ (ดับเมื่อล็อก) · เสาฟื้น · กล่องผนึก (ดับเมื่อแกะ/พัง) · จุดสำรวจ (ดับเมื่อพบ) · โคม/จุดใช้งานในฐาน
- สีต้องตรงความหมาย: เขียว = สำเร็จ/ฟื้น/ปลอดภัย · ทอง = เป้าหมาย/รางวัล · แดงส้ม = อันตราย · ม่วง = ตัวตน/แต่งตัว · ฟ้า = ทรัพยากร

**ฝุ่น + โทนสี (P3c + P3d ✅)**
- `AmbientDust(scene, count)` — สี่เหลี่ยมเล็ก `setScrollFactor(0.85)` ให้ parallax · **ต้องเรียก `update(delta)` และ `destroy()`** (World 35 · ฐาน 24)

- **ColorMatrix ผูกกับกล้องโลกเท่านั้น** → HUD/แผนที่อยู่กล้อง UI ไม่เพี้ยนสีตาม (ข้อดีที่ตั้งใจ)

### 4.14 กฎ UI + TypeScript ที่พลาดจริงใน Session 5 (บังคับ)

1. **`DEPTH` ประกาศด้วย `as const`** → ค่าเป็นชนิดเลขตายตัว (`120`, `121`) ถ้าเขียนพารามิเตอร์เป็น `depth = DEPTH.OVERLAY_TEXT` WITHOUT type annotation → TS สรุปว่ารับได้แค่ `121` ส่ง `120` เข้าไปฟ้อง TS2345
   **กฎ: พารามิเตอร์ที่รับค่า DEPTH ต้องเขียน `depth: number = DEPTH.XXX` ทุกชั้นที่ส่งต่อ** (พลาด 2 รอบใน `LogbookPanel.ts` — ทั้ง `rect()` และ `ui()`)
2. **`continue` ใช้ใน callback ของ `forEach` ไม่ได้** (TS1107 Jump target cannot cross function boundary) → ใน callback ใช้ `return` แทน (ผลเท่ากัน) · ถ้าจะใช้ `continue` ต้องเป็น `for...of`
3. **UiCamera แยกกล้องโดยดู `children.list` ชั้นเดียว + `scrollFactorX/Y === 0`** → **UI ห้ามใช้ Container ซ้อนวัตถุ** (ลูกใน Container ไม่ถูกแยกกล้อง) ให้ใช้ GameObject แบน + `setScrollFactor(0)` + `setDepth()` ทีละชิ้น
4. **.panel/overlay ทุกชิ้นต้อง `setInteractive()` ที่พื้นหลัง** กันคลิกทะลุไปออกดาบ (PlayerActor เช็ค `hitTestPointer`)
5. **แผงที่กินคีย์ (สมุดบันทึก) ต้องกันปุ่มลัดอื่น** — ฉากฐานเช็ก `if (this.logbook) { ...; return; }` ก่อน处理ปุ่ม และหยุดเดินด้วยข้าม `actor.update` + `setVelocity(0)`
6. **สลับขนาด/วาดแผงใหม่ต้อง `killTweensOf` ก่อน destroy** กัน tween ยิงใส่วัตถุที่ตายแล้ว
7. **ห้ามใช้ API ที่ยังไม่ได้ตรวจกับ Phaser 4.2.1** — ของที่ตรวจแล้วใช้ได้: `add.rectangle/circle/ellipse/image/text/graphics/tileSprite` · `fillRoundedRect/strokeRoundedRect/fillEllipse/arc/lineStyle/beginPath/moveTo/lineTo/closePath/fillPath/strokePath` · `generateTexture` · `setBlendMode(Phaser.BlendModes.ADD)` · `setTint/setTintMode/clearTint` · `cam.filters.internal.addColorMatrix` · `physics.add.sprite/body.setCircle/setImmovable` · `tweens.add/killTweensOf` · `time.addEvent/delayedCall`
   **ยังไม่ตรวจ / ห้ามใช้โดยพลการ:** `RenderTexture` · `Container.setScrollFactor` แบบพึ่งพาลูก · `add.triangle/polygon` · `physics.add.existing` แบบ static · Particle Emitter

## 7. AI Workflow Rules

- หนึ่ง Prompt = หนึ่ง Feature (ยกเว้นผู้เล่นสั่ง "ทำเต็มที่/จัดมาเลย")
- ก่อนแก้โค้ด: สรุปแผน 2–4 ประโยค + ไฟล์ที่จะแก้ + ความเสี่ยง
- รออนุมัติก่อนเปลี่ยนโค้ดเดิม
- หลังแก้: บอกวิธีรันและทดสอบเป็นขั้นตอน (เช็กลิสต์สั้น ๆ ตรวจได้จริง)
- ห้ามลบระบบที่ทำงานได้โดยไม่ตรวจผู้เรียก
- **ห้ามแก้ Gameplay + Art พร้อมกัน**
- ห้ามสมมติ Asset มีอยู่จริง — ตรวจ `public/assets` ก่อน
- ใช้ `setTexture()` สำหรับ Animation
- ห้ามเพิ่ม Library ถ้า Phaser/TS ทำได้
- ส่งโค้ดเป็นไฟล์เต็ม หรือ search+replace ที่ชัด (ระบุ "หา" / "แทนที่ด้วย" และบอกว่าแทนที่แค่ไหน)
- **ห้ามอ้างว่าทดสอบแล้วถ้าไม่ได้รันจริง** — ถ้าตรวจจากการอ่านโค้ดอย่างเดียว ให้บอกตรง ๆ ทุกครั้ง
- **API ของ Phaser 4 ต้องตรวจกับตัวไลบรารีจริงก่อนใช้** ไม่ใช้ความจำของ v3
- ตรวจ error ก่อน: F12 → Console + `npx tsc --noEmit`
- จอดำ = ดู Console + Terminal `npm run dev`
- VS Code บน Windows Local เท่านั้น
- **Repomix มีอักขระเพี้ยนจากการแพ็ก** (`expor t`, `prote cted`, `> > >`, `/* ... /`) — อ่านข้ามจุดเพี้ยนได้ แต่ห้ามคัดลอกข้อความเพี้ยนกลับไปเป็นโค้ดจริง
- **ก่อนส่งโค้ด: กวาดคอมเมนต์หาภาษาอื่นปน** (ละเมิดซ้ำ Session 5 — ห้ามเกิดอีก)
- **เมื่อข้อมูลสถานะขัดกัน (แพ็กเก่า vs คำบอกผู้เล่น) ให้ถามหนึ่งครั้งว่าไฟล์ไหนล่าสุด ห้ามเดาแล้วเขียนโค้ดซ้ำของที่ทำแล้ว**

## 9. Style Guide — Paper Cutout

- Art: Paper Cutout / Layered Diorama
- Camera: Top-down
- Palette: น้ำตาลดิน, เขียวมอส, เหลืองอำพัน, แสงเรืองรอง
- Material: กระดาษด้าน มีเส้นใย
- Light: **ซ้ายบน → เงาขวาล่าง** — ยึดผ่าน `LIGHT` ใน config ที่เดียว
- เงาผิดทิศ: เฉพาะร่างปลอมของมายา เท่านั้น (เบาะแส gameplay)
- สีเขียว `0x7dff9b` = สำเร็จ/ฟื้น/ปลอดภัย · ทอง `0xffd166` = เป้าหมาย/รางวัล · แดงส้ม `0xff5a3a` = อันตราย · ม่วง `0xc084fc` = ตัวตน/แต่งตัว · ฟ้า `0x9de7ff` = ทรัพยากร/ข้อมูล · ครีม `0xe8e0c8` = กระดาษ
- **ฐานใช้พาเลตต์อุ่นกว่าสนาม** (`BASE_COLOR` — พื้นน้ำตาลเข้ม ไม้ เหล็กหิน แสงโคมอำพัน) แต่เขียว/ทอง/แดงคงความหมายเดิม
- เสียง: โทนกระดาษ/ลม/ไม้ นุ่ม ไม่แหลมบาด — เสียงหรูขึ้นตามระดับหายากของของที่เก็บ
- **แสงต้องไม่เด่นกว่า Telegraph** — glow อยู่ชั้นใต้ Telegraph เสมอ

| **ลูกศรแผนที่ใช้ทิศการเดิน ไม่ใช่ทิศเมาส์** | 🟢 | PlayerActor ไม่เปิด facing ออกมา — ถ้าจะแก้ต้องเพิ่ม getter อ่านอย่างเดียว |
| **สมุดบันทึกเก็บแค่ 8 ทริป** | 🟢 | สถิติรวมไม่หาย · ถ้าอยากดูย้อนหลังมากกว่านี้ต้องเพิ่ม LOG_MAX + ระบบเลื่อนหน้า |
| บาลานซ์ระยะยาว | 🟡 | ยังไม่ผ่านการเล่นจริงหลายทริปติด — **ตอนนี้มีสถิติจริงในสมุดบันทึกช่วยจูนได้แล้ว** |
| จุดเดิมพันกลางแอเรีย (แบบ 2) | ⏳ | อนุมัติแนวคิดแล้ว ยังไม่สร้าง |
| แฟลช/สีอื่นที่ยังใช้ `setTint` แบบคูณ | 🟢 | ลูกเล่นกระพริบของบอส (ม่วง/แดง/เหลือง) และสีเดือดยังโหมดคูณ — ใช้ได้ ถ้าอยากให้ทึบให้ทำตามกฎ 4.10 |
| คอมเมนต์มีคำภาษาอื่นปน | 🟢 | **Session 5 หลุดซ้ำ 4 ไฟล์** (จีน/อินโดนีเซีย/เกาหลี/สเปน) — มีคำแก้ส่งตามแล้ว แต่ต้องเช็กว่าวางครบ · กวาดทุกครั้งที่แตะไฟล์ |
| คอมเมนต์ `dropChance` ใน `data/minions.ts` | 🟢 | ยังเขียนว่า "ให้อาหารเควสเก็บของ" ซึ่งไม่จริงแล้ว — ตัดท่อนนั้นเมื่อแตะไฟล์ |
| **Repomix เก่าทำให้สรุปสถานะผิด** | 🟠 | เกิดขึ้นจริงใน Session 5 เสียเวลา 3 รอบ — ใช้ตัวชี้วัดแพ็กใหม่หัวข้อบนสุดทุกครั้ง |

### Do not

- ใช้ Points · Pop-up อัปเกรด/กระเป๋า · Backtracking/Chunk Streaming · ต่อท่อห้อง/edge-matching
- โชว์สูตรคูณในหน้าอัปเกรด · ตัดเควสออกจากแอเรีย
- ใช้ `GAME_WIDTH/HEIGHT` หรือ `WORLD_*` ภายในแอเรีย (ใช้ `physics.world.bounds`)
- **ลูกศรชี้ตรงไปเป้าเควส** (ลูกศรทองชี้ประตูที่ปลดแล้วเท่านั้น · แผนที่ไม่เปิดหมอกไม่บอก vị trí เป้า)
- **เควสข้ามแอเรีย / ของฝากข้ามแมพ**
- **ฟื้นเลือดอัตโนมัติตอนข้ามแมพ**
- เปลี่ยน Phaser Version · ลบ Asset เดิม
- แก้ `WorldScene.ts` หรือ `AreaBosses.ts` เพื่อรองรับบอสใหม่ — ใช้ Registry Pattern
- สร้าง `CombatTarget` ใหม่ทุกเฟรม
- **เรียก `setTintFill()`** · **คืนสีหลังแฟลชโดยไม่ `clearTint()` ก่อน**
- **เพิ่มตัวนับเควสเก็บของนอก `tryPickup`** หรือนับของที่ `source` ไม่ใช่ `'ground'`
- **สร้าง `DroppedItem` ใน WorldScene โดยไม่ระบุ `source`**
- **ตั้ง `this.minigame = null` ตอนมินิเกมจบใน `update()`**
- **สร้าง `AudioContext` นอก `sfx.ts`**
- **คำนวณออฟเซตเงาเองใน Entity** — ใช้ `makeShadow/syncShadow` + `LIGHT` เท่านั้น
- **สร้าง glow แล้วไม่ destroy** — ต้องเรียก `destroyGlow` คู่กัน
- **ให้ glow/แสงอยู่ชั้นเหนือ Telegraph**
- **ใช้ Container ซ้อนวัตถุ UI** (UiCamera แยกกล้องไม่ถึงลูก)
- **ใช้ `continue` ใน callback ของ forEach**
- **พารามิเตอร์รับ DEPTH โดยไม่ระบุ `: number`**
- **ใช้ RenderTexture / Particle Emitter / add.triangle / static body API ที่ยังไม่ตรวจกับ Phaser 4.2.1**
- **อ้างว่า "ยังไม่มีระบบนี้" จาก Repomix เก่า** — ตรวจตัวชี้วัดก่อน
- **เขียนโค้ดซ้ำของที่ยืนยันว่าผ่านแล้ว**
- แก้ Gameplay/สมดุลระหว่างทำงานภาพ — แยกคนละรอบ
- **เปิดห้องฝึกให้ผู้เล่นจริง** — ต้องอยู่ใต้ `DEV_TOOLS` เสมอ

## 12. Working Modes

- **Brainstorming Mode** — เสนอทางเลือก 2–4 แบบ ห้ามส่งโค้ดจนกว่าจะเลือก
- **Update Mode (/update)** — ตรวจสถานะจากไฟล์ล่าสุด, แยก Done/Planned, ระบุระดับการยืนยัน
- **Build Mode** — วางแผนสั้น ๆ ทำทีละ Feature ทดสอบทันที
- **Audit Mode (/audit)** — เทียบคำอ้างในเอกสารกับโค้ดจริงทีละข้อ แล้วรายงานเฉพาะจุดไม่ตรง (เกิดจากบทเรียน Session 5)
